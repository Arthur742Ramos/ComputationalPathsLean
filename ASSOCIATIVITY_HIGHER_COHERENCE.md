# Higher associativity coherence: scope and evidence

## Main result

`AssocHigher.allParallel` constructs an inhabitant of `AssocHigher p q` for
arbitrary `p q : AssocRwEq x y`, for arbitrary free-magma trees over any label
type. It includes signed traces, reflexivity, and arbitrary composition trees,
not only directed reductions or the four-leaf pentagon.

The implementation is in
`ComputationalPaths/Path/OmegaGroupoid/AssocHigher.lean`. It extends the original
`Solution.lean` definitions without changing their public statements or the
eight-theorem comparator boundary. This extension is not yet part of that
external comparator or an externally submitted artifact.

## Presentation and proof

`AssocHigher` is Type-valued syntax generated by:

- the associativity pentagon;
- interchange of rewrites in disjoint binary branches;
- naturality squares for each of the three inputs of a rotation;
- contextual closure, higher composition and reversal;
- the structural associativity, unit, and inverse laws for trace composition.

There is no arbitrary-parallel-filler constructor. Naturality and interchange
are generator schemas parameterized by traces; this is not a claim that the
presentation has finitely many individual cells.

`CoherentPeak.fill` exhaustively classifies one-step forks. A root overlap is
identical, critical (the pentagon), or occurs in an argument (naturality).
Disjoint branch steps use interchange; same-branch forks recurse inside the
context. The result contains directed joining traces and a higher certificate
comparing the complete fork boundary.

`AssocSeq.terminalCoherence` uses well-founded recursion on the source tree to
compare complete directed reductions. Each recursive call is at a one-step
reduct, justified by the original termination theorem. `normalizationSquare`
extends that comparison to inverses and composites. `allParallel` then cancels
a common normalizing suffix using derived groupoid-law certificates.

This proves coherence of histories, not merely common-target confluence. In
particular the original two- and three-step pentagon traces remain unequal as
raw syntax, while a higher cell connects them.

## Computational-path boundary

For `label : α → Path a a`, `evalTree` evaluates a tree using actual
`Path.trans`. `evalStep` sends rotations to `Path.Step.trans_assoc` and each
binary context to its corresponding `Path.Step` congruence rule. `evalTrace`
recursively preserves the reflexivity, primitive-step, inverse and composition
constructors in actual `RwEq` witnesses. `evalPentagonShort` checks the concrete
multi-step boundary.

This is a homogeneous loop interpretation. It does not assert that arbitrary
heterogeneously composable strings are represented by this free-magma type,
or that the interpretation is faithful. No inference from equal path
normalizations to `RwEq` is used.

`AssocHigherBridge.lean` extends this to actual `OmegaGroupoid.Derivation₃`
and its `RwEq₃` interface. `evalHigher` handles every source constructor.
Structural composition and inversion map to native structural operations;
pentagon and interchange map to the named native cells. The native pentagon
needs one structural reassociation to match the source's three-step bracketing.

The native system has no primitive horizontal 3-cell or rotation-naturality
constructor. For those cases the bridge reconstructs the comparison from
explicit local diamonds via `nativeAllParallel`. That theorem replays the
terminating local-peak argument inside native 3-cells: each diamond carries the
actual directed joining tails obtained from `CoherentPeak.fill`. It does not
use `contractibility₃`, `rweq_transport`, or arbitrary parallel-cell fillers.
This is a witness interpretation, not a claim that every chosen higher
certificate or contextual lifting is preserved strictly or faithfully.

`eval₂_toRwEq` checks the exact trace-level round trip, and `evalHigherRwEq`
exposes the resulting native higher witness directly between the interpreted
`RwEq` certificates. The source theorem remains independent of the native
tower and its stronger filler rules.

## Relation to existing work

The mathematical coherence principle is classical, not a new coherence
theorem. Mathlib already proves that the free monoidal category has subsingleton
hom-sets, using normalization and an equivalence with a discrete category:
[Mathlib monoidal coherence](https://leanprover-community.github.io/mathlib4_docs/Mathlib/CategoryTheory/Monoidal/Free/Coherence.html).
That theorem includes a unit structure that this nonempty-word presentation
does not address.

Higher-dimensional rewriting and coherent completion are also established
methods, rather than inventions of this artifact. Relevant sources are
Guiraud and Malbos, [Coherence in monoidal track categories](https://arxiv.org/abs/1004.1055),
and Guiraud, Malbos and Mimram,
[A Homotopical Completion Procedure with Applications to Coherence of Monoids](https://drops.dagstuhl.de/entities/document/10.4230/LIPIcs.RTA.2013.223).

The concrete contribution here is a separate, proof-relevant certificate
presentation for the existing free-magma trace syntax: raw histories stay
distinct, while the result supplies explicit higher syntax composed from named
local relations. The trace-level interpretation connects the same syntax to
the computational-path rewrite rules. This gives an inspectable formalization
boundary for normalization and higher rewriting, rather than only an equality
in a category quotient. It does not establish priority over every existing
formalization, minimality of the generators, a complexity bound, or a complete
weak omega-groupoid structure.

## Verification and constructive qualification

Run:

```sh
lake build ComputationalPaths.Path.OmegaGroupoid.AssocHigherBridge
lake env lean scripts/AssocHigherAudit.lean
git diff --check
```

The audit checks the original pentagon distinction, its new higher connection,
the signed-trace theorem, and actual `Path`/`RwEq`/`Derivation₃` interpretations.
It enforces an axiom allowlist and traverses the bridge's transitive proof-body
dependencies to reject arbitrary-parallel and proof-irrelevant transport
fillers, while requiring the named pentagon, interchange and local diamond
generators to occur. Axiom printing reports only Lean's standard `propext` and
`Quot.sound` for both global theorems and the bridge; no `Classical.choice`,
`sorryAx` or custom axiom occurs.
`CoherentPeak.fill` reports only `propext`.

The result constructs a Type-valued certificate in Lean's logic, without
classical choice. `coherentStep_wellFounded` removes the old termination
theorem's unnecessary witness selection by eliminating `Nonempty` directly
inside `Prop`. Some definitions remain `noncomputable` because of Lean's
recursor/code-generation interface. This is a logical certificate construction
relative to Lean's propositional extensionality and quotient soundness, not a
claim of an extracted executable algorithm or a complexity bound.

The separate higher-coherence CI job runs this build and audit. The repository
had pre-existing Lean 4.33 proof-script failures in the imported path and tower
modules; the accompanying repairs preserve their theorem statements. This is
a targeted validation, not a claim that every repository module builds.
